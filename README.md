# Home Security System
This Home Security System will be able to detect and identify an invader without the use of a camera by using innovative sensors.

## 🚀 Project Overview
This project will protect the authorized users home without the need of the Authorized users assistance.

## 🛠️ Tech Stack & Components
* **Languages: Python, C++, Embedded C
* **Hardware/Microcontrollers:** FPGA, ESP32, LCD Screen
* **Sensors/Interfaces:** Grid Sensor, Ultrasonic Sensor, Biometric sensor, 
* **Protocols/Tools:** Git, Linux Environment, MQTT

## 📈 System Architecture & Current Progress
-Phase 1, Operation Analysis: At this phase will show the relationship between the actors that are involved in the operation.
-Phase 2, (IN PROGRESS) System Analysis: At this phase will show the relationship between the actors and the system involved during the operation.
-Phase 3, Logical Architect: This define of the system is made
-Phase 4, Physical Architect: Define the components that will be used to make the system.

## 🔍 Engineering Focus
This repository serves as a practical sandbox to apply rigorous systems engineering fundamentals out of the office, focusing heavily on:
Hardware-in-the-Loop (HIL) testing configurations.
Root cause analysis of firmware and sensor timing anomalies.
Clean, modular software integration practices.
